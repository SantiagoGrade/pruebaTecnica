# Prueba Técnica — Matriz Caracol

## Stack
- **Backend**: Node.js + TypeScript + Express + Vitest

## Levantar el proyecto

### Backend
```bash
cd backend
npm install
npm run start   # → [http://localhost:3000](http://localhost:3000/api/caracol/5)
npm run tests   # → Vitest
```
## Endpoint principal
`GET /api/caracol/:n` — n entre 3 y 15
